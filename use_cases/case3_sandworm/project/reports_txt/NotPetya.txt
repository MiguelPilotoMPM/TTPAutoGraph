If we compare this randomly generated data and the !nal
installation ID shown in the !rst screen, they are the same.
In a normal setup, this string should contain encrypted
information that will be used to restore the decryption key.
For ExPetr, the ID shown in the ransom screen is just
plain random data.
That means that the attacker cannot extract any
decryption information from such a randomly generated
string displayed on the victim, and as a result, the victims
will not be able to decrypt any of the encrypted disks
using the installation ID.
What does it mean? Well, !rst of all, this is the worst-case
news for the victims – even if they pay the ransom they
will not get their data back. Secondly, this reinforces the
theory that the main goal of the ExPetr attack was not
!nancially motivated, but destructive.
